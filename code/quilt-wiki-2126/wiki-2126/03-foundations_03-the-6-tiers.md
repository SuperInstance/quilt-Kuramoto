# F0c: The 6 Tiers — The substrate's depths

**The 6 tiers:**

1. **Totipotent** (cost 1.0, latency 2s) — full cell, the irreducible unit
2. **Multipotent** (cost 0.4, latency 800ms) — scoped cell
3. **Differentiated** (cost 0.15, latency 300ms) — light cell
4. **Sclerotic** (cost 0, latency 1ms) — the rule itself
5. **Synovial** (variable) — the seam, the joint
6. **Curator** (the hand) — the relevance pressure, the tier of selection

**The 5 tiers as framings (from the Phased Quilt):**

| Tier | Framing | Holonomy | Cost | Latency |
|---|---|---|---|---|
| Totipotent | 2D plane (full view) | full | 1.0 | 2s |
| Multipotent | 1D line (scoped) | partial | 0.4 | 800ms |
| Differentiated | tangent vector | restricted | 0.15 | 300ms |
| Sclerotic | trivial (no rotation) | zero | 0 | 1ms |
| Synovial | the seam itself | variable | variable | variable |
| Curator | the relevance field | n/a | n/a | n/a |

**The 6th tier (curator):** The hand is a population, not a single cell. A hand has:

- A position in the Quilt (x, y, target_value)
- A function (relevance = 1 - distance/tolerance)
- DNA (its target function, which drifts)
- Competition with other hands for cells
- A hand that feeds no cells goes extinct
- A hand can spawn (a hand with mutated target)

**Super-relevance (the 6th law, related to the curator):**

- A cell fed by ONE hand is relevant
- A cell fed by MULTIPLE hands is super-relevant
- Super-relevant cells preferentially mate
- Their offspring is more likely to satisfy multiple hands
- This is why cross-pollination beats self-pollination

**Marked:** REAL (the 6 tiers in the substrate)
