# M4: Snell's Law as Conservation — `p∥ = n sin θ` is conserved

**The statement:** When light crosses an interface between two media with refractive indices `n₁` and `n₂`, the component of the wave's momentum *parallel to the interface* is conserved: `n₁ sin θ₁ = n₂ sin θ₂`.

**The math:**

- The wave's momentum (in units of ħk) is `p = n sin θ` in the direction of propagation
- The parallel component (relative to the interface) is `p∥ = n sin θ`
- Across the interface: `p∥(before) = p∥(after)`

**The deep fact:** This is the rigorous reason "relative symmetry" works. Refraction is a purely *relative* transformation — there's no absolute coordinate in the result. Each bend is a local opinion reconciled globally by the variational principle (Fermat).

**Error analysis:** Pattern one surface from the next and the *common* errors cancel in the joint (differential measurement — this is why interferometry beats metrology-by-ruler), while absolute placement accumulates every error additively.

**Why this is the math for the Splined Lantern:**

The Photolith Foundry of 2063 failed expensively because they wanted *absolute* control — every facet placed by coordinate, every weight etched to spec, tolerances chased to nanometers. It never worked, because an error in one absolute coordinate poisons every relation downstream, and there are always errors. They were building with a tape measure the size of a galaxy and losing the thread at every joint.

Iunia Ootax's revolution was "stop placing facets, start lofting them." Pattern the second surface off the first. **Relative symmetry.** Each new pass absorbs the sins of all previous passes into one longer, fairer line. The precision doesn't live in any cut. It lives in the *relation between cuts* — the only place precision has ever actually lived.

**Marked:** REAL (Snell 1621; momentum-conservation interpretation is 20th century)
