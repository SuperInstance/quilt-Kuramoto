# Upstream repo READMEs — documentation without code

Each file here is the README of a **separate GitHub repository** in the
`SuperInstance` org. **Their source code is not in this archive.** A README is a
claim about a repo, not the repo.

The org listing captured in `archive/github-api-scrapes/SuperInstance-repos-page1.json`
shows 100 repos on page one alone; the org's own profile claims "500+ repos".
This folder holds ~30 of those READMEs.

Treat these as a map of the intended ecosystem, and as evidence of what the
author was building toward — not as evidence that it exists and works.

`spline-and-tminus/` groups the multi-agent-timing and spline-routing repos.
The `t-minus` / `agent-sync` protocol described there is the thing that
`research/quantum-bridge` later maps onto Kuramoto oscillator synchronisation.
