# Provenance — how the original structure was reconstructed

The dump arrived flat. Every placement below rests on evidence quoted from the
files themselves, not on guesswork.

## Evidence types used

1. **Path-flattened filenames.** `docs_MATHEMATICS.md` → `docs/MATHEMATICS.md`;
   `include_cell.h` → `include/cell.h`; `docs_academic_quilt-calculus.md` →
   `docs/academic/quilt-calculus.md`; `quilt-esp32_main_docs_INDEX.md` → repo
   `quilt-esp32`, branch `main`, `docs/INDEX.md`.
2. **Provenance headers in source files.** The strongest evidence:
   - `qm_vessel2c.py` — `# quilt-esp32 — firmware/qm_vessel2c.py`
   - `build_corpus.py` — `# quilt-esp32 — tools/reflex/build_corpus.py`
   - `qm2c.py` — `# Vendored from SuperInstance/cell-cascade, branch edge-benchmarks, tools/qm_compiler/benchmarks/qm2c.py — vendored 2026-08-26. Logic unaltered.`
   - `quilt_vm.c` — `/* Vendored verbatim from SuperInstance/quilt-vm-c, src/quilt_vm.c (commit 4adf4ab…) */`
   - `quilt_cells.cuh` — `// Part of SuperInstance/quilt-cuda.`
   - `tower_oil_pressure_port.c` — `GENERATED by tools/tower/emith.py from oil-pressure-port.cell.yaml`
   - `t1_first_fabric.v` — `TUTORIAL 1 … Run: bash examples/t1_first_fabric/run.sh`
3. **Build files naming their own paths.** `Makefile (2)` self-identifies as
   *"quilt-verilog — root Makefile"* and its `FORMAL_SBY` list gives the `formal/`
   paths; `Makefile (1)` as *"firmware/Makefile"*; `Makefile (3)` as *"quilt-cuda — Makefile"*.
4. **Machine-generated records naming workdirs.** `AUDIT-SNAPSHOT.json` records
   `"workdir": "formal/cell_core.tick"` for each proof, confirming `formal/`.
5. **`.sby` `[files]` sections** listing `rtl/q_*.v` and `formal/f_*.v`.

## Name collisions resolved

Several distinct files collided on one name because the download flattened paths.
These were **not** duplicates and were separated, not deleted:

- **`main.c` × 5** — five different programs (232/125/144/423/377 lines), each
  naming its own directory in its header comment. Now under
  `code/quilt-esp32/host/host_{reflex,opcodes,oil,nmea,eileen}/main.c`.
- **`DOCTRINE.md` × 2** — quilt-verilog's 12-line *"llama.cpp, but Verilog"* vs
  quilt-llvm's 70-line *"working laws for every lane"*. Both kept, in their repos.
- **`GLOSSARY.md` × 2** — quilt-verilog's 205-line glossary vs quilt-llvm's
  59-line *"fleet words and compiler words"*. Both kept.
- **`Makefile` × 3** — quilt-verilog root, quilt-esp32 firmware, quilt-cuda root.
- **`paper-219 (1).md`** — the `(1)` copy was the *only* copy; renamed, not deleted.
